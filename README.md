# PDF Reader · Obsidian 文献阅读插件

**右键读文献 · 选中即批注 · 关键词自动进标签 · 扫描版截图 OCR**

面向论文阅读的 Obsidian **桌面端**插件。右键任意 PDF 或 Markdown →「开始阅读」，左边文献、右边笔记；选中文字就能批注，批注过的位置在 PDF 里一直亮着；点高亮跳笔记、点笔记里的「定位」跳回原文；新建笔记时把 PDF 的作者关键词自动写进 frontmatter；扫描版可以框选交给本机视觉模型识别成文字。

> 插件 ID `pdf-reader` · 需要 Obsidian **1.12.7+** · **仅桌面端** · 核心功能完全离线（全插件只有两处联网，见[安全与隐私](#安全与隐私)）

## 功能一览

| 功能 | 你能得到什么 |
| :-- | :-- |
| **一键阅读** | 右键任意 PDF / Markdown →「开始阅读」：左边打开文献，右边按模板新建（或复用）阅读笔记，光标直接落在笔记里 |
| **选中即批注** | 选中文字弹出批注菜单写入 callout，`Ctrl/Cmd + 多选`可批量；批注落在**你正在写的那篇笔记**，不会写到别处 |
| **PDF 持久高亮** | 批注过的位置在 PDF 中一直高亮，颜色与透明度可调，重开文件仍在 |
| **双向跳转** | 点 PDF 高亮 → 跳到笔记里对应批注；点笔记里的「定位」→ 跳回 PDF 那一页（文件没打开时自动分屏，不覆盖当前标签页） |
| **关键词自动提取** | 新建阅读笔记时读取 PDF 的作者关键词段，写进 frontmatter `tags`；没有关键词段的论文用标题 + 摘要兜底 |
| **词表由你自己维护** | 设置里一行一个概念，如 `机器学习 = machine learning, ML`：中英写法、全称缩写、单复数、连字符变体收敛成同一个标签。**插件不内置任何词条** |
| **快速打标签** | 工具条「标签」按钮或快捷键唤起选择器（支持模糊搜索、显示说明），把 `#标签` 写进光标处 |
| **标签改名同步** | 在词表里改名后一键同步到全库笔记，逐篇汇报成功 / 失败，可重试 |
| **安全删除标签** | 先列全库实际出现的次数，再逐行预览 `改动前 → 改动后`，影响较大时要求手打标签名确认 |
| **截图 OCR 批注** | 框选 PDF 任意区域 → 本机 LM Studio 视觉模型识别文字 → 写进笔记，区域持久高亮（扫描版 / 无文本层 PDF 可用） |
| **截图批注** | 框选区域直接存成图片写进笔记，同样带持久高亮与回跳 |
| **DeepSeek 窗口** | DeepSeek 网页既可作为可拖拽浮动窗口，也可在工作区以标签页打开，一键上传当前 PDF / 笔记 |
| **文件管理增强** | 已有阅读笔记的 PDF 显示小图标；文件列表里的长标题自动换行，不再被 `…` 截断 |

## 安装

### 手动安装（推荐）

1. 打开 [Releases 页面](https://github.com/Mongfayi/obsidian-literature-reader/releases)，在最新版本的 Assets 里下载这 6 个文件：

   | 文件 | 是否必需 | 说明 |
   | :-- | :-- | :-- |
   | `main.js` | 必需 | 插件主体 |
   | `manifest.json` | 必需 | 插件清单 |
   | `styles.css` | 必需 | 样式（主题可覆盖） |
   | `pdf-reader-<版本>-cmaps.zip` | 中文 PDF 必需 | CMap 字符映射表，解压后形成 `cmaps/` 目录 |
   | `pdf.worker.min.mjs` | 建议 | PDF.js worker；缺失时回退到内置副本 |
   | `pdfjs-fallback.mjs` | 建议 | 回退用 PDF.js 库；缺失时回退到 Obsidian 自带 pdf.js |

2. 把它们放进 vault 的 `.obsidian/plugins/pdf-reader/`，并将 `pdf-reader-<版本>-cmaps.zip` **解压到同一目录**（zip 内是扁平结构，直接解压即可得到 `cmaps/`）。
3. 重启 Obsidian →「设置 → 第三方插件」→ 启用 **PDF Reader**。

装好的目录应形如：

```
.obsidian/plugins/pdf-reader/
├── main.js
├── manifest.json
├── styles.css
├── pdf.worker.min.mjs
├── pdfjs-fallback.mjs
└── cmaps/            ← 由 cmaps.zip 解压而来，共 169 个文件（168 个 .bcmap + LICENSE）
```

> **为什么 cmaps 要单独打包？** CMap 是中日韩等 CID 字体的字符映射表。缺了它，中文 PDF 的**文本提取**（关键词提取、批注定位）会失败或乱码。169 个文件逐个下载不现实，因此打成单个 zip（约 0.95 MB）。从仓库克隆的用户不用管，`cmaps/` 已在仓库里。

### 从源码构建

```bash
npm install
npm run build   # tsc 类型检查 + esbuild 打包，产出 main.js，并从 node_modules/pdfjs-dist/cmaps 复制 cmaps/
```

## 使用指南

### 阅读：左文献，右笔记

- **右键 PDF**：按命名模板创建 / 复用 `ReadingNotes/{PDF名} 阅读.md`。
- **右键待读的 md**（例如章节原文）：左边打开这篇 md，右边创建 / 复用 `ReadingNotes/{md名} 阅读.md`，并把它标记为「正在阅读的文献」——选中它的文字即可批注进右侧笔记。
- **右键已经是阅读笔记的 md**：打开它对应的文献 + 这篇笔记本身，不另建笔记（找不到对应文献时只提示）。
- 分屏始终是「左文献 / 右笔记」并垂直排列，焦点落在笔记上，可以直接开始写。

### 批注与跳转

- **批注落点跟随光标**：批注、截图批注、OCR 批注、标签都写入你光标所在的那篇笔记。想让多篇 PDF 汇集到同一篇笔记，保持那篇笔记作为落点即可；**没打开笔记时会明确提示**，不会自动建笔记、也不会静默写到别处。
- **默认不附带原文**：文字批注只插入「定位」链接，OCR 批注只写识别文字，截图批注只写图片，保持笔记干净。点工具条「附带原文」按钮后，三种批注都会带上定位链接与 `> 笔记：` 提示行。
- **批注链接统一显示为「定位」**（可在设置里改别名）。旧笔记里已有大量 `PDF名, 页面 N` 的长链接时，对该笔记执行命令「将当前笔记中的 PDF 批注链接显示文字改为「定位」」即可，链接目标不变，只缩短显示文字。
- **点「定位」不会打乱现有分屏**：来源笔记已在别的窗格打开就复用那一格并滚动它；未打开则先复用空栏，否则在笔记旁边已有的那一栏新开标签（左右分屏时不会多出第 3 栏），只有笔记独占一栏时才新开一栏，**始终不替换当前标签页**。随后只点亮被批注的那段 `==` 文字。
- **Markdown 批注**：在 md 笔记顶部工具栏把它标记为「正在阅读的文献」后，选中文字会在右上角出现「批注到笔记」浮动按钮；来源文字自动包上 `==` 高亮，目标笔记写入 `[!pdf-annotation]` 蓝框或纯定位链接。删除「定位」链接时，对应的 `==` 高亮同步撤销。标记只在本次 Obsidian 运行期间有效。

### 关键词

- 新建阅读笔记时自动读取 PDF 的「关键词 / Keywords / Key-words / Index Terms」段，去噪后写进 frontmatter `tags`；每篇最多标签数可调（默认 8）。
- **插件不内置任何词条**：词表就是设置里的一个文本框，一行一个概念：

  ```
  机器学习 = machine learning, ML, machine-learning
  模型评估[方法] = model evaluation, model assessment
  显著性* = significant, significance
  ```

  | 写法 | 含义 |
  | :-- | :-- |
  | `=` 左边 | 最终写进笔记的规范标签 |
  | `=` 右边 | 别名：命中任一写法都归并到这个标签 |
  | `标签后 *` | 泛化词，只在标题命中时参与兜底推断 |
  | `[方括号]` | 分类，只用于状态栏统计 |
  | `#` / `//` 开头 | 注释行 |

- 写错的行只跳过该行并在下方报出行号，其余照常生效；改完 **600 ms 自动生效**，无需重载插件。
- 「导入…」支持 vault 内的 `.json` / `.txt` / `.md`（JSON 兼容 `{version, concepts}`、裸数组、字符串数组三种形态），「导出」把当前词表写成 JSON 存到 vault 根目录，方便备份或多机同步。
- 也可以把词表放成插件目录下的 `keyword-lexicon.json`（已在 `.gitignore` 中排除）：设置里的词表为空时，插件首次加载会自动读进来。
- 中英双关键词段的论文以中文段为主，英文段只补充能归并的概念，避免同一标签出现中英文两遍；Elsevier 逐行关键词、中文换行截断、大小写与连字符变体都能解析。
- 完全没有关键词段的论文（扫描版、部分出版社格式）用标题 + 摘要命名词表兜底；扫描版无文本层时仍可能没有标签。
- **给旧笔记补关键词**：打开 PDF 或它的阅读笔记 → 命令「为当前文献笔记添加关键词」→ 勾选要追加的标签 → **只追加** frontmatter `tags`，正文与已有标签不动。

### 标签

- 在「设置 → PDF Reader → 标签」里逐行维护标签（名称 + 描述，＋ 添加 / ↑↓ 调序 / ✕ 删除）。描述只显示在选择器里，不写进笔记，可省略。每个标签还会自动生成一条「插入 #标签」命令，可自行绑定快捷键。
- 点 PDF 工具条或 Markdown 编辑器顶部的「标签」按钮（或执行「快速添加标签」）→ 搜索并选中 → 插入到你**光标所在的那篇笔记**，形成 `[[…|定位]] 我的想法 #方向`。点 PDF 上的按钮不会把落点抢到该 PDF 自己的笔记。
- **改名**：直接在词表里改，下方立刻出现「#方向 → #方针」的待同步项 → 点「同步到笔记」→ 确认预览即可批量更新所有笔记。每个标签有永不改变的内部 id，所以改名是精确配对，不存在猜错。改描述不会改动任何笔记。
- **删除**：标签行的 `✕` 从词表移除；若笔记里还有引用，会接着问是否一并清理。也可用命令「删除标签（从所有笔记中移除某个标签）」单独清理。全库扫描 → 逐行预览 → 影响较大时手打标签名确认；只删标签本身与一个相邻空格，不动该行其他内容、不删行。
- **失败会明确告知**：改名和删除都逐篇汇报成功 / 失败，失败的笔记保留旧标签、待办不清空，可直接重试。插件**不提供撤销**——整篇覆盖式还原会连带抹掉同步之后写的内容。

### DeepSeek 窗口

- 点左侧栏机器人图标或执行命令打开；设置里可选默认以「浮动窗口」还是「标签页」打开（浮动窗口可拖动标题栏、拖边缘改大小，位置与大小自动记住）。
- 点「加载文件」把当前 PDF / 笔记内容上传到聊天框；命令「将当前阅读文件上传到 DeepSeek 聊天框」也可触发。
- 地址可在设置里替换成你自己的自建页面（须为 http/https）。

### 截图 OCR 批注（扫描版专用）

1. 设置 → PDF Reader → 截图 OCR 批注：填写 LM Studio 服务器地址（默认 `http://127.0.0.1:1234`）与视觉模型名（推荐 `paddleocr-vl-1.6`，留空按推荐顺序自动选择）。
2. 在 PDF 视图工具条点「截图 OCR 批注」（crop 图标）→ 拖拽框选区域 → 模型识别文字并写入笔记。
3. 识别区域在 PDF 中持久高亮（边框显示、内部不填充，颜色与文字批注共用同一设置），可点击跳回笔记对应批注。
4. 识别期间工具条按钮会禁用，避免并发请求互相插队；输出被截断或模型名写错会有提示。

## 常见问题

**中文 PDF 提取不到文字、批注定位乱？** 没装 `cmaps/`。下载 `pdf-reader-<版本>-cmaps.zip` 解压到插件目录，重启 Obsidian。

**批注时提示「请先把光标放到要批注的笔记里」？** 这是设计如此：批注落点跟随光标，没打开笔记时不猜目标。先点开目标笔记、把光标放进去，再批注。

**新建的笔记没有关键词标签？** 依次检查：该 PDF 是否有文本层（扫描版没有）→ 是否有作者关键词段（没有就走标题 + 摘要兜底）→ 词表是否为空（词表为空时只清洗原文关键词、不做归并）。可以随时用命令「为当前文献笔记添加关键词」补一次。

**OCR 提示连接失败？** 确认 LM Studio 已启动并加载视觉模型、地址端口与设置一致、模型名拼写正确（写错会直接 404 而不再无意义重试）。

**旧笔记里的批注链接还是长串？** 对那篇笔记执行命令「将当前笔记中的 PDF 批注链接显示文字改为「定位」」，或在设置里改「批注链接别名」后重新批注。

**Obsidian 1.13 里按设置名搜不到本插件？** 本插件使用命令式 `PluginSettingTab.display()` 以保持对 1.12 的兼容，未采用 1.13 的声明式设置 API，因此在设置页搜索中不会命中。

### 源码结构

`main.ts` 负责装配，功能按模块拆分在 `modules/`，每个模块实现统一的 `PluginModule` 接口（`onload` / 设置页区块 / 命令与事件注册），互不直接依赖：

| 模块 | 职责 |
| :-- | :-- |
| `PdfReaderModule` | 阅读入口、分屏、工具条、批注写入、链接缩短 |
| `PdfHighlightModule` / `HighlightBase` | PDF 文本批注的持久高亮 |
| `PdfJumpModule` | 笔记 ↔ PDF 双向跳转 |
| `MarkdownReadingModule` / `MarkdownAnnotationSync` | Markdown 文献标记与 `==` 高亮 ↔ 定位链接同步 |
| `KeywordModule` / `keywordEngine` / `keywordLexicon` | 关键词段解析、词表解析与别名归并（纯逻辑，不依赖 Obsidian API） |
| `QuickTagModule` / `TagSyncModule` / `tagVocabulary` | 标签选择器、改名同步、安全删除 |
| `ScreenshotModule` / `BaseCropModeModule` / `ScreenshotHighlightModule` | 框选截图批注与持久高亮 |
| `OcrModule` / `OcrService` / `OcrHighlightModule` | LM Studio OCR 调用、输出清洗、区域高亮 |
| `DeepSeekModule` | 浮动窗口 / 标签页的 `webview` 容器 |
| `ReadingNoteMarkerModule` / `noteContentCache` / `noteNaming` | 文件管理器标记、笔记缓存、命名模板 |
| `pdfLinkIndex` | 「哪些笔记链接到这篇 PDF」的共享缓存 |
| `SearchEnhancementModule` / `WordCountFixModule` | 搜索忽略链接、字数统计修正 |
| `SettingsTab` | 命令式设置面板（分区、词表编辑器、待同步区） |

几个实现上的取舍：

- **链接索引共享缓存**：批注、跳转、截图、OCR 四个模块原先各自遍历 `metadataCache.resolvedLinks`（一次批注就是 4 次全库扫描），现在统一走 `pdfLinkIndex.notesLinkingToPdf()`，按对象引用 + 1 秒 TTL + 500 条上限缓存。
- **批注可点击但可回退**：只有带配对记录的「定位」链接会被插件接管并点亮 `==` 段落；你自己手写的同名链接、没配对记录的旧链接仍是 Obsidian 原生行为。
- **重复打开不抖动**：写盘统一走防抖 + 关闭设置页时冲刷，避免最后几百毫秒的改动丢失。
- **单文件产物**：`main.js` 由 esbuild 打包（production 开启 minify），PDF.js worker 与回退库作为独立文件按需加载，`cmaps/` 在构建时从 `node_modules/pdfjs-dist/cmaps` 复制。
