# 文献阅读助手 (Obsidian Literature Reader)

一个面向文献阅读的 Obsidian 桌面端插件：PDF 一键阅读、批注到笔记、关键词自动提取、批注持久高亮、截图 OCR 批注，并集成 DeepSeek 浮动窗口/标签页。

> 插件 ID：`pdf-reader` · 仅桌面端（依赖 Electron / PDF.js）

## 功能特性

- **一键阅读**：右键**任意文件** →「开始阅读」，自动垂直分屏（左文献 / 右笔记，焦点在笔记上）。
  - 右键 PDF：按模板创建/复用 `ReadingNotes/{PDF名} 阅读.md`
  - 右键**待读的 md**（如 reference 下的章节原文）：左边打开这篇 md，右边创建/复用 `ReadingNotes/{md名} 阅读.md`，并把它标记为「正在阅读的文献」——选中它的文字就能批注进右侧笔记
  - 右键**已经是阅读笔记的 md**（在阅读笔记文件夹内，或名字就叫「… 阅读」）：打开它对应的文献 + 这篇笔记本身，不另建笔记（找不到对应文献时只提示）
- **关键词自动提取**：阅读时自动提取 PDF 关键词写入笔记 frontmatter，作为 Obsidian 标签（似乎只适配了部分格式的文献）
- **批注到笔记**：选中文字即可批注（callout 格式），支持 `Ctrl/Cmd + 多选` 批量批注
- **Markdown 批注**：在 Markdown 笔记顶部工具栏可标记「正在阅读的文献」；标记后在笔记中选中文字，右上角出现「批注到笔记」浮动按钮。点击后来源文字自动包上 `==` 高亮，目标笔记光标处写入 `[!pdf-annotation]` 蓝框（附带原文开启时）或纯定位链接。点击目标笔记里的「定位」链接时，导航与 PDF 模式一致且不会打乱现有分屏：来源笔记已在其它窗格打开就**复用那一格并滚动它**；未打开则先复用已有的空栏，否则在**笔记旁边已有的那一栏**里新开一个标签（左右分屏时不会再多分出第 3 栏），只有笔记独占一栏时才新开一栏；**始终不会替换当前标签页的内容**，随后**只点亮被批注的那段 `==` 文字**（判据是「这条链接有配对记录」，所以只有本插件写出的「定位」链接会被接管：你自己手写的同名链接、以及没有配对记录的旧链接都保持 Obsidian 原生行为 —— 旧链接会按标题闪整节，而不是退回闪标题）；删除「定位」链接时，来源 md 中对应的 `==` 高亮会同步撤销。标记只在本次 Obsidian 运行期间有效，关闭即清空
- **批注落点跟随光标**：批注、截图批注、OCR 批注与标签都写入你**光标所在的那篇笔记**（即你刚在写的那一篇）；想多篇 PDF 汇集到同一篇笔记时，保持那篇笔记作为落点即可。**没打开笔记时会明确提示无法批注**，不会自动建笔记、也不会静默写到别处
- **批注持久高亮**：批注过的位置在 PDF 中持久高亮显示（可配置颜色与透明度）
- **高亮 ↔ 笔记双向跳转**：点击 PDF 中的高亮区域跳到笔记中对应批注；点击笔记中的 PDF 链接跳回 PDF 对应位置；目标文件未打开时自动分屏打开（笔记链接 → PDF 在笔记左侧打开；高亮 → 笔记在 PDF 右侧打开），不会覆盖当前页面
- **批注链接短标签**：所有 PDF 批注链接统一显示为短标签「定位」，不再显示冗长的 `PDF名, 页面 N`。
- **默认批注模式（不附带原文）**：默认关闭「附带原文」；文字批注只插入「定位」链接，OCR 批注只写识别文字，截图批注只写图片，保持笔记简洁。
- **附带原文模式**：打开「附带原文」后，三种批注都会附带定位链接与「笔记：」提示行；文字批注写入原文，OCR 批注写入识别文字，截图批注同时写入图片、定位链接与提示行。
- **DeepSeek 窗口/标签页**：DeepSeek 网页聊天既可作为可拖拽、可最小化的浮动窗口，也可在 Obsidian 工作区以标签页打开；支持一键上传当前 PDF / 笔记内容
- **截图 OCR 批注**：在 PDF 视图工具条点「截图 OCR 批注」按钮，框选区域用 LM Studio 视觉模型识别文字并批注到笔记，OCR 区域持久高亮（适合扫描版/无文本层 PDF）
- **截图批注持久高亮**：截图批注区域会在 PDF 中显示黄色边框高亮（内部不填充），并可点击跳回笔记对应批注
- **文件管理器标记**：在左侧文件管理器中，已有阅读笔记的 PDF 会显示一个小图标；笔记创建/删除/重命名后自动更新
- **快速添加标签**：在插件设置里逐行维护标签（名称 + 描述），阅读时点 PDF 工具条或 Markdown 编辑器顶部工具栏的「标签」按钮，或按快捷键，即可把 `#标签` 插入到阅读笔记的光标处；选择器支持模糊搜索并显示每个标签的说明
- **标签改名同步**：每个标签有永不改变的内部 id，所以改名是精确记录的、不存在猜错配对的问题。在设置里改完名字，下方会出现「#方向 → #方针」的待同步项，点「同步到笔记」即可批量更新所有笔记；改描述不会改动任何笔记
- **安全删除标签**：删除前先列出全库实际出现的标签及次数，再显示逐行 `改动前 → 改动后` 预览，影响较大时要求手打标签名确认；只删标签本身和一个相邻空格，不碰该行其他内容、不删行
- **失败会明确告知**：改名和删除都会逐篇汇报成功/失败；有失败的笔记保留旧标签名、待办不清空，可直接重试。（**不提供撤销** —— 整篇覆盖式的还原会连带抹掉你在同步之后写的内容，风险高于收益）

## 安装

### 手动安装

1. 下载`main.js`、`manifest.json`、`styles.css`（及 `cmaps/` 目录，仓库内已附带）
2. 放入 vault 的 `.obsidian/plugins/pdf-reader/` 目录
3. 重启 Obsidian，在「设置 → 第三方插件」中启用「文献阅读助手」

### 从源码构建

```bash
npm install
npm run build   # 产出 main.js，并自动复制 cmaps/
```

## 使用

1. 在文件管理器中右键**要读的东西** →「开始阅读」：右键 PDF 就按模板建/复用它的阅读笔记；右键一篇 md（章节原文、别人的稿子等）则左边打开这篇 md、右边建一篇 `{md名} 阅读.md` 当笔记本（这篇 md 同时被标记为「正在阅读的文献」，选中文字可直接批注进右边）；右键已经在 ReadingNotes 里的笔记，则打开它对应的文献 + 这篇笔记本身
2. 阅读时选中文字 → 弹出批注菜单，写入右侧阅读笔记；按住 `Ctrl/Cmd` 可连续多选批量批注
3. 点击 PDF 中的高亮区域 → 跳到笔记中对应批注；点击笔记中的 `定位` 链接 → 跳回 PDF 对应位置（PDF 未打开时会在笔记左侧分屏打开）
4. 点击左侧栏机器人图标或使用命令打开 DeepSeek；设置中可选「浮动窗口」或「标签页」默认方式，也可用命令「在标签页打开 DeepSeek」。点「加载文件」可将当前 PDF / 笔记上传
5. 在 PDF 视图工具条点「截图 OCR 批注」按钮（crop 图标）→ 拖拽框选区域 → LM Studio 识别文字并写入笔记（需先在设置中配置 LM Studio 服务器地址）
6. 如果旧笔记里已有大量冗长的 `PDF名, 页面 N` 链接，可在该笔记上执行命令「将当前笔记中的 PDF 批注链接显示文字改为「定位」」，链接目标不变，只缩短显示文字。
7. **快速打标签**：在 设置 → 文献阅读助手 → 标签管理 里逐行维护标签（＋ 添加标签 / 直接改名称 / ↑↓ 调序 / ✕ 删除）。阅读时点 PDF 工具条或 Markdown 编辑器顶部工具栏上的标签按钮，或按你在「设置 → 快捷键」中为命令「快速添加标签」绑定的按键 → 搜索并选中标签 → **插入到你当前光标所在的那篇笔记**（即你刚在写的那一篇），最终形成 `[[…|定位]] 我的想法 #方向`。点 PDF 上的按钮不会把落点抢到该 PDF 自己的笔记；只有当你没有正在编辑的笔记时，才回退到该 PDF 的阅读笔记（未打开则自动追加到末尾）。
8. **改标签名**：直接在标签行里把 `方向` 改成 `方针`，下方会立刻出现「#方向 → #方针」的待同步项 → 点「同步到笔记」，确认预览即可批量更新所有笔记；点「撤销改名」则把名字改回去。改描述不会触发任何笔记改动。
9. **删标签**：标签行的 `✕` 从词表移除；若笔记里还有该标签的引用，会接着问你是否一并清理。也可以用「从笔记中删除标签 → 选择标签…」单独清理某个标签。有失败的笔记会列出来，可直接重试。

## 设置项

| 参数 | 说明 |
|------|------|
| 阅读笔记文件夹 | 阅读笔记存放路径（相对 vault 根目录，默认 `ReadingNotes`） |
| 阅读笔记命名模板 | 新建笔记文件名规则，`{name}` 为 PDF 文件名（默认 `{name} 阅读`） |
| 笔记正文模板 | 新建阅读笔记的正文内容（默认「## 信息 / ## 疑问」） |
| 高亮颜色 / 透明度 | 批注持久高亮的外观（文字批注与 OCR 区域高亮共用，修改即时生效） |
| 批注链接别名 | 批注回链 PDF 的链接显示文字（默认 `定位`） |
| 批注提示行 | 批注 callout 末尾的提示行（默认 `> 笔记：`） |
| 默认附带原文 | 「附带原文」按钮的初始状态；工具条切换也会自动记住 |
| 文件管理器阅读笔记标记 | 为已有阅读笔记的 PDF 显示小图标（可关闭） |
| DeepSeek 地址 | 嵌入 DeepSeek 窗口/标签页的网页地址 |
| DeepSeek 默认打开方式 | 点击机器人图标时以「浮动窗口」或「标签页」打开；也可用命令单独打开 |
| LM Studio 服务器地址 | OpenAI 兼容接口地址（默认 `http://127.0.0.1:1234`） |
| OCR 模型 | 自由填写视觉模型名（推荐 `paddleocr-vl-1.6`）；留空按推荐顺序自动选择 |
| 请求超时（秒） | 单次 OCR 请求超时时间（默认 120） |
| 最大输出令牌 | 单次识别请求最大输出长度（默认 8192） |
| OCR 提示词 | PaddleOCR-VL 用任务词如 `OCR:` |
| 清洗 OCR 输出 | 去除模型输出噪音；关闭后保留 LaTeX 命令与代码块原文 |
| 放大目标短边（像素） | 框选区域短边不足时等比放大再识别（默认 512，0 = 关闭放大） |
| 放大倍率上限 | 小区域放大的最大倍数（默认 4，范围 1-8） |
| 标签列表 | 标签的唯一真源，逐行编辑（名称 + 描述 + 上下移 + 删除）。描述只显示在选择器里、不写进笔记，可省略 |
| 工具条「标签」按钮 | 是否在 PDF 工具条显示「标签」按钮；关闭后仍可用命令「快速添加标签」 |
| 从笔记中删除标签 | 清理笔记里某个标签的正文引用（全库扫描 → 逐行预览 → 二次确认） |

## 安全说明

- **OCR API Key 以明文存储**：LM Studio API Key 保存在插件目录的 `data.json`（即 vault 的 `.obsidian/plugins/pdf-reader/data.json`）中，Obsidian 插件 API 不提供加密存储。
- 如果你的 vault 通过 iCloud / OneDrive / Syncthing / git 等同步，密钥会随之传播。建议：不使用 LM Studio 鉴权时留空该字段；使用鉴权时定期在 LM Studio 中轮换密钥，并考虑在同步配置中排除 `.obsidian/plugins/pdf-reader/data.json`（排除后需在本机重新填写一次）。
- 插件依赖 Electron 专有 `webview` 标签与部分 Obsidian 内部 API，**仅支持桌面端**（`manifest.json` 已声明 `isDesktopOnly: true`）。

## 技术说明

- 基于 [PDF.js](https://github.com/mozilla/pdf.js)（pdfjs-dist，Apache-2.0）、[pdf-lib](https://github.com/Hopding/pdf-lib)（MIT）、[fflate](https://github.com/101arrowz/fflate)（MIT）
- `main.js` 由 esbuild 打包，PDF.js worker 内联；`cmaps/` 在构建时从 `node_modules/pdfjs-dist/cmaps` 自动复制

## 更新记录

- 新增：**右键 Markdown 也能「开始阅读」：左边读文献，右边记笔记**。此前只有 PDF 有该菜单项。现在右键一篇待读的 md（例如 `reference/GWAS中文版/` 下的章节原文）→「开始阅读」会在右边按命名模板建/复用 `{md名} 阅读.md`（frontmatter 写 `source:` 指向这篇 md），左边打开这篇 md 本身，并把该 md 标记为「正在阅读的文献」，选中文字即可批注进右侧笔记；再次右键同一篇 md 会复用已有笔记，不重复创建。
- 补充规则：**已经是阅读笔记的 md**（位于阅读笔记文件夹内，或名字就叫「… 阅读」）不会被再套一层「阅读」，右键它打开的是它对应的文献 + 这篇笔记本身。判据不是「有没有 pdf 字段」——精读版章节原文也带 pdf 字段，但它们是文献不是笔记。
- 修复：**截图/OCR 框选跨视图误批注**。框选监听挂在窗口上却不校验页面归属，导致「看着 PDF B、却在 A 上框选」时把 B 的文字与坐标写成指向 A 的批注；现已在入口校验页面必须属于本次进入截图模式的视图，命令入口也改为优先取最近活动的 PDF。
- 修复：**OCR 识别期间禁用工具条按钮**，避免连续框选并发发起请求（本地单卡会逐个跑满超时，且并发写入同一光标位置会互相插队）。
- 修复：**标签改名可能写出无效标签**。改名输入框若带首尾空格，词表会被规范化但待同步记录不会，同步后写成 `# 名`（`#` 后有空格，不是合法标签）；现已在失焦时用规范化后的名字重新登记。
- 移除：**「撤销上次标签同步」功能**（含备份文件）。整篇覆盖式还原会连带抹掉同步之后新写的内容；改为逐篇汇报成功/失败，失败保留待办可重试。
- 修复：OCR 输出被 `max_tokens` 截断时现在会提示；模型名写错（404）不再无意义重试。
- 修复：手工粘贴的 PDF 链接现在能立即建立高亮与跳转索引（此前要重新打开该 PDF 才生效）。
- 修复：OCR / 截图高亮补上「读盘失败保留旧索引」保护，避免一次读取失败就把整篇高亮抹掉。
- 修复：笔记被拖到**弹出窗口**后批注可能误报「请先把光标放到要批注的笔记里」——已改为直接持有编辑器实例并校验其容器仍在文档上，与窗口拓扑无关。
- 修复：标签同步/删除时若个别笔记写入失败，此前会静默跳过并清空待办；现在会列出失败笔记并保留待办，可直接重试。
- 改进：PdfReaderModule 恢复完整 TypeScript 类型标注，全项目不再有 @ts-nocheck。
- 变更：**批注落点改为跟随光标，并移除「主文献」按钮**。批注/截图/OCR/标签现在统一写入你光标所在的那篇笔记；没打开笔记时会明确提示无法批注，不再自动创建笔记或静默改写到他处。原先「主文献」的汇集能力由「保持目标笔记作为落点」自然覆盖。
- 调整：**标签改用稳定 id 管理**。标签不再是纯文本行，而是带永不改变内部 id 的结构化条目（设置面板中逐行编辑）。因此改名是精确记录的 —— 不再需要「描述指纹 / 行号配对」这类推断，也不会再出现需要人工确认的「推测配对」。旧版文本框内容与更早的 `凡例“#”.md` 都会在首次运行时自动迁移。
- 新增：**标签改名同步与安全删除**。改名后可一键同步到所有笔记，删除标签带全库扫描、逐行预览与二次确认，两者写入前都会备份并支持一键撤销。
- 新增：**快速添加标签**。从「凡例」文件（默认 `凡例“#”.md`，每行「标签名：描述」）读取标签词表，经 PDF 工具条「标签」按钮或自定义快捷键唤起选择器，把 `#标签 ` 插入阅读笔记光标处；插入落点与批注一致（都是你光标所在的那篇笔记），并自动处理标签前后的空格以保证被识别。选择器支持模糊搜索、显示标签说明。
- 调整：工具条「附带原文」按钮改为纯图标（状态通过悬停提示区分），为工具条腾出空间。
- 修复：使用 pdf-search 等其他插件打开/跳转 PDF 时，批注持久高亮可能消失的问题。原因是在索引尚未建成（打开 PDF 后防抖重建完成前）或重建中笔记读取失败时，渲染事件会把瞬态"空索引"当成权威删除已显示的高亮层；现在这类情况下会保留旧高亮层，并在索引重建完成后自动恢复正确高亮。
